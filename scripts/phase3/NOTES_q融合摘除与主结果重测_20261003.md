## 上传安装与闸序

同步本包更新的 hook、`eval_ddm_val.py`、`verify_qfusion_removal.py`、`run_qfusion_removed_mainline.py`、`smoke_ddm.py`、本说明；四臂后续还需同步 `run_depth_attribution.py`。服务器从根目录执行：

```bash
ROOT=/path/to/ultralytics
PKG=/path/to/Phase3_Reproducibility_Repository/scripts/phase3
P2=/path/to/FieldGuide_Phase2_FRP_20260916
RUNS=/path/to/runs/phase3
W=/path/to/frp_stageA_v1/weights/best.pt
CKPT=/path/to/ddm_v3_train_20261001/last.pt
RGBT=/path/to/RGBT-3M/RGBT
M3FD=/path/to/M3FD_hardneg_scene_v1
DV=/path/to/DVHN400
export PYTHONPATH="$ROOT:$PKG:$P2:$PYTHONPATH"
export PHY_F3D_SCALE=50 PHY_DDM_W1=0.5 PHY_DDM_W2=0.3 PHY_DDM_W3=0.2
export PHY_FG_MODE=fixed PHY_FG_ALPHA=0.5 PHY_FRP=1 PHY_STAGE=3 PHY_FG=1 PHY_FIELD_IMPL=heatfield
export PHY_FRP_TAU=0.045 PHY_FRP_CC_IMPL=batched PHY_FRP_TOPK=0 PHY_DDM_VETO_C=0.25

DST=$ROOT/ultralytics/nn/modules/ddm_fusion_hook.py
cp -n "$DST" "$DST.bak_qfusion"
test -f "$DST.bak_qfusion" && grep -q 'new_pur=t\*' "$DST.bak_qfusion" || { echo 'Old q hook backup missing/wrong'; exit 1; }
cp "$PKG/ultralytics/nn/modules/ddm_fusion_hook.py" "$DST"
md5sum "$DST" "$DST.bak_qfusion"

python -u "$PKG/verify_qfusion_removal.py" \
  --weights "$W" --ddm-ckpt "$CKPT" --rgbt-root "$RGBT" \
  --phase2-package "$P2" --old-hook "$DST.bak_qfusion" \
  --device cuda:2 --samples 20 \
  --out "$RUNS/equivalence_qfusion_removal_20261003.json"

python -u "$PKG/run_qfusion_removed_mainline.py" \
  --weights "$W" --ddm-ckpt "$CKPT" --rgbt-root "$RGBT" \
  --m3fd-root "$M3FD" --m3fd-manifest "$M3FD/hardneg_test_manifest.jsonl" \
  --dvhn-root "$DV" --dvhn-manifest "$DV/manifest.jsonl" \
  --phase2-package "$P2" --equivalence "$RUNS/equivalence_qfusion_removal_20261003.json" \
  --device cuda:2 --out "$RUNS/qfusion_removed_mainline_20261003"
```

等价性 JSON 每张记录四个逐 bit 检查：旧/新 hook 的 DDM-off 净化场及检测框相等、新 hook DDM-on（θ=0）与 off 净化场及检测框相等；并验证 off 不生成 `p_ddm`、on 生成 `p_ddm` 且无 `q`。`all_pass=true`、样本数≥20 才放行。主线脚本逐次检查 cuda:2 至少 8 GiB 空闲；M3FD FP 若偏离 54/50 超过 ±5 或 person FP≠363，DVHN FP 偏离 388/327 超过 ±5，就写 `deviation_alarm.json` 停在当前轮，不调参。

主线目录按 `m3fd/`、`rgbt_val/`、`dvhn400/` 各有 `metrics.json`、`detections3d.jsonl` 总表，`theta_*/` 有逐 θ 文件；`combined/` 保存原评估脚本的完整双链产物。`summary.json` 主表恰为三链×两 θ 的六行，DVHN 重复跑到的 RGBT 指标单列 `rgbt_repeatability`，不混入主表。框级转储与硬负逐图 FP 一并留存。

四臂衔接：本任务完成后，四臂 A 直接引用 `qfusion_removed_mainline_20261003/combined/m3fd_theta_0.001/`，B/C/D 在新 hook 上跑，不再重测 A。
